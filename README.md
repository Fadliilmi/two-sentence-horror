A program that writes one original two-sentence horror story — exactly two sentences, under 400 characters — for make.fun's Two-Sentence Horror bounty. Quiet dread, no gore: a year of polite notes from the tenant in 4B, until tonight's note turns out to be in the narrator's own handwriting, dated before he moved in.

## Run it

```sh
node main.ts
```

It writes the story to `/output/entry.txt`.
